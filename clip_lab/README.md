# Clip Lab

Browser tool for authoring, cleaning, and packing game-ready football animation data for **PannaVerse**.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5174`.

## Workflow
1. **Drop Character**: Drop your rigged Mixamo character (`player.fbx`).
2. **Drop Clips**: Drop your Mixamo and Rokoko FBX animation clips.
3. **Inspect & Clean**: Use the 3D viewport, transport bar, and timeline to mark ball touches, preview ball physics, and mirror moves.
4. **Export**: Export packed `player.glb` and `clips.json` directly into PannaVerse.
